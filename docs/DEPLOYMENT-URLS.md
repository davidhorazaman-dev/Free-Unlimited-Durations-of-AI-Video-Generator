# Complete Website and Distribution URLs

- Production Website: https://longestformaiexplainervideogenerator.ai/
- GitHub Pages: https://davidhorazaman-dev.github.io/Free-Unlimited-Durations-of-AI-Video-Generator/
- Static API Console: https://longestformaiexplainervideogenerator.ai/api/v1/

GitHub Pages serves the frontend only. The real JSON API must be a separate HTTPS service. Configure it with `?api=https://YOUR-API-HOST/api/v1` or `window.LONGEST_FORM_API_BASE`.

This removes the former “Failed to fetch” / HTML-instead-of-JSON failure caused by treating static Pages hosting as an API server.

Distribution targets: Windows x64, macOS x64/arm64, Linux x64/arm64, and source archives.

“Infinite duration” means an unbounded chunked project timeline. Real providers, computers, storage, network, accounts and encoders still have finite resource limits.
